# 🎓 Multilingual Campus Chatbot

## 📌 Overview
Campus offices receive hundreds of repetitive queries every day — about fee deadlines, scholarship forms, timetable changes, and more. Students often prefer Hindi or other regional languages, leading to long queues, miscommunication, and delays.  

This project provides a **multilingual conversational assistant** that answers student queries instantly, in their preferred language. By embedding the chatbot into the college website and popular messaging platforms, it ensures **24/7 access to information** while reducing the burden on staff.

---

## ✨ Features
- 🌐 **Multilingual Support** — Understands and responds in **English, Hindi, and 5+ regional languages**.  
- 🤖 **AI-Powered Intent Recognition** — Accurately interprets student queries.  
- 🔄 **Context Management** — Maintains conversation flow across multiple turns.  
- 👩‍🏫 **Human Fallback** — Connects to staff when queries need manual intervention.  
- 📝 **Daily Conversation Logs** — For review and continuous improvement.  
- 🔒 **Privacy First** — Ensures student data is protected.  
- 🛠 **Volunteer-Friendly** — Designed for easy updates and maintenance by student teams.  

---

## 🚀 Tech Stack
- **Frontend**: HTML, CSS, Tailwind  
- **Backend / Bot Logic**: Node.js / Python (customizable)  
- **Database**: (Optional) Firebase / MongoDB for FAQs & logs  
- **AI/Chatbot Service**: Rasa / Dialogflow / Botpress / Custom NLP  
- **Deployment**: College Website + Messaging Platforms (WhatsApp, Telegram, etc.)  

---

## 🏗 How It Works
1. **Ingest FAQs** — Bot is trained on institutional FAQs and circulars.  
2. **Understand Queries** — Students ask in their preferred language.  
3. **Respond or Redirect** — Bot replies instantly, or connects to staff if needed.  
4. **Log Conversations** — All chats are saved for improvement.
